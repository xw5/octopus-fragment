# Octopus Fragment

类 FastKeys 的片段管理工具，基于 **AutoHotkey v2**，零第三方依赖。

**当前版本：v1.0.1**

> 📖 普通用户请看使用说明：[简体中文](docs/UserGuide.zh-CN.md) | [English](docs/UserGuide.en.md)

## 功能

- **快速搜索面板**：唤出后输入关键词实时过滤，↑↓ 选择、Enter 插入、Esc 关闭
- **触发符 + Tab 唤起**：输入 `/` 按 Tab 唤起面板；输入 `/ul` 按 Tab 直接以 `ul` 为关键字唤起（触发符可在设置里改）
- **缩写自动展开**：输入 `;;缩写` 立即替换为片段内容（可配前缀/开关）
- **中英文界面**：中文 / English 一键切换，跟随系统或手动指定；窗口标题、菜单、提示、示例数据全部跟随
- **托盘菜单**：按分类列出片段，点选即插入
- **GUI 管理窗口**：搜索/分类/列表，右上角「⋯」下拉菜单里是新增、编辑、删除、复制、插入、设置、数据目录、退出
- **列表右键菜单**：右键任意片段 → 插入 / 编辑 / 删除 / 复制（空白处右键也能弹出，只是全部置灰）；右键会先选中该行再弹菜单；复制会在**原片段前面**插一条副本，名称为「原名 + 序号」（我的邮箱 → 我的邮箱2 → 我的邮箱3），缩写自动清空（避免两条热字符串互相覆盖），图片/文件片段的资源单独另存一份
- **三种内容类型**：
  - 文本：多行文本，粘贴到当前光标
  - 图片 / 文件：从剪贴板捕获，插入时原样还原到剪贴板再粘贴（支持 PNG/JPG/GIF/任意文件）
- **动态变量（模板）**：内容里写 `{{变量名}}`，插入时弹出填写窗口（输入框 / 下拉选择 / 多行），并支持 `{{date}}`、`{{clipboard}}`、`{{cursor}}` 等内置变量

## 使用

1. 用 **AutoHotkey v2** 运行 `OctopusFragment.ahk`（`C:\Program Files\AutoHotkey\v2\AutoHotkey.exe`）。
   - 可选：用 Ahk2Exe 编译为独立 exe 后开机自启。
2. 托盘图标会出现；首次运行自动生成 `data\` 下的默认配置与示例片段。

### 默认热键

| 操作 | 热键 |
|------|------|
| 快速搜索 | `Ctrl + Alt + Space` |
| 管理窗口 | `Ctrl + Alt + M` |
| 触发符唤起搜索 | 输入 `/` 后按 `Tab`（可带关键字，如 `/ul` + `Tab`） |
| 缩写展开 | 输入 `;;email` 之类，立即展开 |
| 托盘双击 | 打开管理窗口 |

热键可在「管理窗口 → 设置」中修改，语法：`^`=Ctrl `!`=Alt `+`=Shift `#`=Win。

### 界面语言（中英文）

`设置 → 语言` 三选一：**跟随系统**（默认，按系统默认界面语言自动判断）/ **简体中文** / **English**。

- 保存后立即生效：窗口标题、按钮、菜单、消息框、托盘、动态变量教程一并切换，无需重启
- 已切换过的窗口会自动按新语言重建（管理窗口原来开着会重新打开）
- 存档在 `data\config.json` 的 `lang` 字段（`auto` / `zh` / `en`），也可手工改
- 片段数据（名称、分类、内容）属于用户数据，不会被翻译；只有**首次生成为空库**时的示例片段按当前语言生成

### 触发符 + Tab（斜杠命令式唤起）

- 输入 `/` 再按 `Tab` → 唤起搜索面板（关键字为空）
- 输入 `/ul` 再按 `Tab` → 唤起面板且关键字已填 `ul`，光标在末尾可继续输入
- 面板里 `Esc` 取消 → `/ul` 原样留在原窗口，不会白输
- 面板里选中片段（Enter/双击）→ 插入前自动删掉原窗口里的 `/` 或 `/ul`，只留下片段内容
- 插入需要填写变量、在填写窗口点了取消 → 同样会把 `/` 关键字删干净，不留残字
- 输入法处于中文状态时，`/` 可能被输入法转成 `、`，此时不会触发；请在英文/半角状态下使用
- 触发符、总开关、等待时长都在「设置」里：`搜索触发符`、`启用「触发符 + Tab」唤起搜索`、`触发等待(ms)`
- 只有「纯小写字母/数字/下划线/短横线/点，且不超过 20 字符」的关键字才会被当成命令；超过等待时长没按 Tab 则按普通输入处理，不会打断正常打字

### 新增片段

1. 打开管理窗口，点「新增」。
2. 填名称、缩写、分类、标签。
3. 类型选「文本」→ 在内容框填入文本（支持多行）。
4. 类型选「图片/文件」→ 先把图片或文件复制到剪贴板，再点「从剪贴板捕获」。
5. 保存后立即生效（热字符串、托盘菜单自动刷新）。

### 动态变量

内容里写 `{{变量名}}`，插入时会先弹出填写窗口，确认后才粘贴渲染结果。文本、热字符串、`/`+Tab、托盘菜单四条入口都生效。

内置变量（不用填写，自动替换）：

| 写法 | 结果 |
|------|------|
| `{{date}}` | 2026-11-20 |
| `{{time}}` / `{{datetime}}` | 09:43 / 2026-11-20 09:43:16 |
| `{{year}}` `{{month}}` `{{day}}` | 2026 / 11 / 20 |
| `{{date:yyyyMMdd}}` | 自定义格式（FormatTime 语法），`time`/`datetime` 同样支持 |
| `{{clipboard}}` | 插入时剪贴板里的文本 |
| `{{cursor}}` | 不输出字符，粘贴后光标停在这里 |

自定义变量在编辑窗口的「动态变量」框里配置，每行一条：`名称|标签|类型|默认值或选项`

| 类型 | 说明 | 第四列 |
|------|------|--------|
| `text` | 单行输入（默认） | 默认值 |
| `memo` | 多行输入 | 默认值 |
| `select` | 下拉选择 | 选项，逗号分隔 |

示例：

```
内容：  【日报】{{date}}
        姓名：{{name}}   环境：{{env}}
        今日完成：{{done}} 光标：{{cursor}}

变量：  name|姓名|text|
        env|环境|select|开发,测试,生产
        done|今日完成|memo|
```

- 只定义了 `{{name}}` 却没写变量行也能用：会自动按单行输入框弹窗
- 变量名可留空标签；规格里写了但内容里没用的变量也会显示
- 编辑窗口的两个快捷键：
  - 「内容」右侧的 **插入占位符 ▾**：点击插入 `{{}}` 并把光标停在两个花括号中间；鼠标停在按钮上 0.4 秒弹出下拉，列出「动态变量」里已定义的变量（含内置变量子菜单），点选即插入到光标处
  - 「动态变量」右侧的 **插入模板 ▾**：点击或悬停弹出下拉，直接插入 `text` / `memo` / `select` 三种模板行
- 记不住语法时：鼠标移到编辑窗口「动态变量」标题右侧的 `?` 上会弹出速查教程，点一下可看全文
- 每次填写的值会记在片段里（`lastvals`），下次自动带出，改完直接回车
- 弹窗里 `Enter` = 插入，`Esc` = 取消（取消不插入，也不动剪贴板）
- 粘贴前会尝试切回原窗口；切不回去会提示并放弃插入，避免粘到别的程序

### 备份 / 迁移

片段数据即 `data\snippets.json`（标准 JSON，可手工编辑后用托盘「重新加载」）。
手动备份/迁移直接复制该文件与 `data\assets\` 目录即可。

## 数据结构

`snippets.json` 每个片段字段：

| 字段 | 说明 |
|------|------|
| id | 唯一 ID |
| title | 名称 |
| trigger | 缩写（不含前缀） |
| category | 分类 |
| type | `text` / `image` / `file` |
| content | 文本内容（type=text 时用），可含 `{{变量}}` |
| fields | 动态变量规格（文本，每行 `名称\|标签\|类型\|默认值或选项`） |
| lastvals | 上次填写的变量值（自动保存，可删） |
| file | 资源文件名（type≠text 时用，位于 assets/） |
| tags | 标签，供搜索 |
| usage | 使用次数 |
| created / modified | 时间戳（A_Now 格式） |

## 构建与发版

版本号只维护一处：`lib\Actions.ahk` 里的 `App.Version`；入口脚本中
`;@Ahk2Exe-SetVersion` 的 exe 元数据由构建脚本自动同步，无需手动改。

```
build.bat            按当前版本号构建（编译 + 打 dist\...-win64.zip + 生成发布说明模板）
build.bat 1.0.4      先把版本号改为 1.0.4 再构建
```

要求：本机装有 AutoHotkey v2（脚本自动在 `Program Files\AutoHotkey\Compiler` 下找
`Ahk2Exe.exe`，也可用环境变量 `AHK2EXE` 指定）。

发版收尾按脚本末尾打印的步骤执行：补发布说明 → commit → `git tag vX.Y.Z` →
push → GitHub Releases 上传 zip。

## 已知限制

- 本工具为单用户本地脚本；数据存于本地 JSON，无云同步。
- 修改 `snippets.json` 后需用托盘「重新加载」（或重启脚本）生效。
- 图片/文件片段以完整剪贴板快照保存，原生保真。
- `{{cursor}}` 靠粘贴后左移光标实现，个别不支持光标移动的控件（部分网页富文本）可能不生效。
