# Octopus Fragment 使用说明

> 面向普通用户的图文使用手册。开发文档请看 [README.md](../README.md)。
> [English](UserGuide.en.md)

Octopus Fragment 是一个 Windows 剪贴板片段工具：把你常用的文字、图片、文件存成「片段」，随时一键插入到任何输入框里。适合常用邮箱签名、日报模板、客服话术、代码块的人。

---

## 1. 安装与启动

1. 安装 [AutoHotkey v2](https://www.autohotkey.com/)（安装时选 v2）。
2. 双击 `OctopusFragment.ahk` 运行。
3. 启动后屏幕右下角托盘区会出现章鱼图标，并自动生成一份示例片段供你试用。

想让它开机自启：右键托盘图标 → 打开数据目录，给 `OctopusFragment.ahk` 创建快捷方式，放进「开始菜单 → 启动」文件夹即可。

---

## 2. 三秒上手：插入你的第一个片段

1. 按 **`Ctrl + Alt + Space`** 唤出搜索面板。
2. 输入关键词（如「邮箱」），列表实时过滤。
3. 按 **↑↓** 选中，按 **Enter** —— 内容已插入到你刚才打字的地方。

按 **Esc** 关闭面板，不打扰你。

---

## 3. 四种插入方式

| 方式 | 怎么用 | 适合场景 |
|------|--------|----------|
| 搜索面板 | `Ctrl + Alt + Space` → 搜 → Enter | 偶尔用的片段 |
| 触发符 + Tab | 打 `/` 按 `Tab`；或打 `/ul` 按 `Tab` 直接搜「ul」 | 边打字边唤起 |
| 缩写展开 | 打 `;;email` 立即变成完整内容 | 高频短片段 |
| 托盘菜单 | 右下角托盘图标 → 按分类点选 | 鼠标党 |

> 用触发符唤起后按 Esc 取消，`/ul` 会原样留在输入框，不会白打。

---

## 4. 管理你的片段

按 **`Ctrl + Alt + M`** 打开管理窗口（双击托盘图标也行）。

- **新增**：右上角「⋯」菜单 → 新增，填名称、分类、内容即可。
- **编辑 / 删除 / 复制**：右键列表中的片段。复制会生成「原名2」「原名3」这样的副本。
- **三类内容**：
  - **文本**：多行文字，直接填。
  - **图片**：先复制图片（截图也行），在编辑窗口点「从剪贴板捕获」。
  - **文件**：同上，先复制文件再捕获。
- **分类**：片段可归到不同分类，窗口顶部按 Tab 页切换。

---

## 5. 动态变量：让片段「活」起来

在内容里写 `{{变量}}`，插入时会弹出小窗口让你填，确认后才粘贴。

**示例**：日报模板

```
【日报】{{date}}
姓名：{{name}}   环境：{{env}}
今日完成：{{done}}
```

插入时自动弹出窗口让你填「姓名、环境、今日完成」，`{{date}}` 自动变成当天日期。

**内置变量**（不用定义，直接用）：

| 写法 | 效果 |
|------|------|
| `{{date}}` / `{{time}}` / `{{datetime}}` | 当天日期 / 时间 / 日期时间 |
| `{{clipboard}}` | 你剪贴板里当前的文字 |
| `{{cursor}}` | 粘贴后光标停在这个位置 |

记不住语法？编辑窗口「动态变量」右侧有个 **?**，鼠标放上去就出速查教程。上次填过的值会自动记住，下次弹窗已带出，直接回车即可。

---

## 6. 设置

管理窗口右上角「⋯」→ 设置：

- **热键**：修改唤出面板 / 管理窗口的快捷键（`^`=Ctrl `!`=Alt `+`=Shift `#`=Win）。
- **触发符**：默认 `/`，可改；缩写前缀默认 `;;`，也可改或关闭。
- **语言**：跟随系统 / 简体中文 / English，切换立即生效，无需重启。

---

## 7. 备份与搬家

所有数据都在程序目录的 `data\` 文件夹里：

- 备份：复制整个 `data\` 文件夹。
- 搬到新电脑：装好 AutoHotkey v2 + 程序文件，再把 `data\` 放回原位置即可。

---

## 8. 常见问题

**Q：输入 `;;email` 没反应？**
确认输入法在英文/半角状态；中文状态下 `;;` 或 `/` 可能被输入法吃掉。

**Q：图片片段插入后不对？**
图片片段以剪贴板快照保存，插入时先还原到剪贴板再粘贴，目标程序需支持粘贴图片。

**Q：改了片段但不生效？**
保存片段后立即生效；若你是手工改的 `data\snippets.json` 文件，请用托盘菜单「重新加载」。

**Q：{{cursor}} 没把光标停到想要的位置？**
个别网页富文本编辑器不支持光标移动，属已知限制。

**Q：想关掉自动展开？**
设置里关闭「缩写展开」即可，其余功能不受影响。
